The Engineering Problem

The Cost of Code-Local Blindness

In microservice architectures, a single field type change looks harmless in a local git diff. But standard CI, linters, and PR reviews cannot see across repository boundaries.

Standard PR Review

What Your Team Sees

  • Local File Diff: discount_tier: str → dict in one isolated file.
  • Passing Tests: Local unit tests pass because only the producer is checked.
  • Zero Graph Awareness: Unaware that checkout-api parses this contract as raw text.
  • Hidden Cascade: Unaware that order-orchestrator depends on checkout-api downstream.
  • Outcome: Merged to production → Runtime outage → Emergency rollback.
BlastGate Connected Agent

What BlastGate Discovers

  • AST Code Graph: Gristle indexes functions and routes connected to PriceQuote.
  • Validated Mapping: Maps code symbol to pricing-api-v2.discount_tier via contract rules.
  • Multi-Hop FalkorDB Traversal: Traverses 3 hops to identify 5 affected downstream services.
  • MCP Tool Investigation: Detects missing fallback, computes betweenness centrality (4.0), and flags past outage INC-2041.
  • Defensible Decision: Authoritative BLOCK with clear reviewers (eng-alpha, eng-bravo) and $43,000 assumed SLA risk.
The Architecture

Connected Dual-Graph Intelligence

BlastGate connects two complementary views of the world: static source code ASTs and dynamic runtime service topologies.

Layer 1

Code Graph (AST)

Indexed via Gristle in an isolated environment. Extracts Python AST nodes: classes, methods, endpoints, and symbol references.

Indexed: PriceQuote, 6 functions, 2 routes
Bridging Layer

Validated Contract Mapping

Strict schema mappings in blastgate.map.json connect code-level symbols to published service endpoints with verified validation statuses.

Status: validated (non-ambiguous)
Layer 2

FalkorDB Service Graph

Cypher queries traverse service dependencies, consumers, SLAs, and historical incidents. Computes graph algorithms like betweenness centrality.

Queries: Multi-hop blast radius, SLA exposure
Layer 3

MCP Agent Investigation

Allowlisted Model Context Protocol tools let the agent investigate blast radius, verify fallback readiness, and gather evidence before deciding.

Tools: 5 schema-validated MCP actions
