Architecture, Systems & Trust

BlastGate is engineered as a production-grade systems intelligence console. Explore the complete technical stack, security boundaries, FalkorDB Cypher traversal mechanics, and honest disclosures.

System Component Map

Frontend & Delivery

Vanilla Console & Strict CSP

Built with zero heavyweight dependencies (HTML5, Vanilla CSS, ES Modules). Enforces a strict Content Security Policy (no inline scripts, no untrusted origins, clickjacking protection).

Files: web/app.js, web/view.js, web/styles.css
API Gateway

FastAPI Core Engine

Serves deterministic endpoints (/api/analyze, /api/simulate) and the investigation runner (/api/agent/investigate). Implements sliding-window rate limiters and auth guards.

Files: blastgate/api.py
Code Graph Subprocess

Gristle AST Extractor

Executes inside an isolated environment (.gristle-venv). Parses repository AST, maps symbols to schemas, and generates tamper-resistant review reports.

Files: blastgate/codegraph.py, scripts/setup_gristle.sh
Connected Graph Engine

FalkorDB Graph Database

High-throughput graph database running on Redis protocol. Stores service nodes, CONSUMES_FIELD contracts, DEPENDS_ON topologies, SLAs, and historical incidents.

Files: blastgate/graph.py, Cypher multi-hop traversals
Tool Interface

Allowlisted MCP Server

Implements the Model Context Protocol (MCP) specification over stdio. Exposes 5 allowlisted tools with schema validation, PR pinning, and duplicate execution guards.

Files: blastgate/mcp_server.py, blastgate/tools.py
Authoritative Policy

Deterministic Verdict Engine

Evaluates multi-hop topology, consumer fallbacks, critical service exposures, and incident recurrence. Decisions are 100% reproducible and immune to LLM hallucination.

Files: blastgate/verdict.py, blastgate/analysis.py
What-If Branching

GRAPH.COPY Sandbox

Duplicates active graph state into a temporary copy in FalkorDB. Simulates hypothetical consumer fallback mitigations without polluting the production graph.

Files: blastgate/simulation.py
Temporal Memory

Investigation Memory Graph

Stores prior investigation verdicts and AST review hashes in a dedicated graph. Revalidates historical claims against active graph topology upon recall.

Files: blastgate/memory.py

Trust, Transparency & Rigor

Synthetic Demonstration Data

To ensure reproducible judging without exposing proprietary corporate infrastructure, services (e.g. checkout-api), incidents (INC-2041), SLAs, and engineers (eng-alpha) are synthetic demo parameters. The $43,000 figure is an assumed exposure calculation (sum of synthetic hourly penalty rates × assumed outage duration), not historical accounting.

Type-Level vs. Runtime Link Limits

Gristle indexes Python AST structural references (functions and routes connected to classes). BlastGate explicitly states that a type-level reference does not prove that a given function executes that field at runtime.

Deterministic Engine Authority

The agent planner gathers facts and generates natural-language explanations, but the verdict is computed strictly by deterministic rules. An LLM cannot override a BLOCK or weaken an SLA violation.

Offline Planner Integrity

The verified offline demo runs with AGENT_PROVIDER=deterministic. The console truthfully displays this badge and does not claim that a live model autonomously selected the tool calls during the offline run.
